# P05 临时旅人

`traveler.glb` 是本项目原创的临时古装人物，由 `tools/author-p05-avatar.py` 完整生成，没有下载第三方人物、贴图或动作。GLB 自包含材质和四组动作，可离线载入。重新运行生成脚本可得到相同字节。

人物为 1.75 米白衣、青玉饰边的中性简化造型，正面朝本地 -Z，脚底位于 y=0。采用关节节点层级及 GLB TRS 动画，未宣称使用蒙皮或写实人体。站立、行走、飞行、坠落均只改变显示关节；根节点没有位移动画。运行时由 Babylon AnimationGroup 权重混合，物理位置始终来自 LocalSession。

这是用户选定方向的临时模型，不代表最终人物美术精度或全部动作已验收。模型、材质和动作来源均为本仓库内的生成脚本，不引入额外第三方资产许可。
