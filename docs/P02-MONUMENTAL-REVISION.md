# P02 巨殿尺度与繁复构件修订

当前分支 `feat/tiangong-p02-monumental-20261021`。前版 `feat/tiangong-p02-20261021` 和原 16 个资料文件保持原样。新会话先读根目录 `PROJECT_STATUS.md`；通用云端运行和累计门禁方法见 `docs/P02-VISUAL-STUDY.md`。

本轮根据用户“宫殿要巨大、纷繁复杂”的反馈调整真实三维构件与空间尺度。不是仅改变镜头、缩小人物或改变配置中的标称尺寸。

| 项目 | 前版 | 当前修订 |
| --- | --- | --- |
| 主屋面脊高 | 约 70 米 | 约 145.3 米；脊饰略高 |
| 主柱柱身实际高度 | 34.2 米 | 64.98 米 |
| 台面高度 | 12 米 | 18 米 |
| 主殿横向／纵深 | 原作者空间 | 横向 1.35 倍、纵深 1.55 倍 |
| 人物身高 | 1.75 米 | 1.75 米，保持实际高度 |
| 巨柱数量 | 24 | 36 |
| 屋顶层次 | 双重檐 | 三重檐 |
| 每处斗拱层次 | 5 层 | 8 层，并加入斜撑、卷曲托臂 |

新增细节为实际网格：加密檐下梁枋、交叉藻井与花心、双层门框、连续菱形门额纹样、两侧分层格窗及檐角卷饰。栏杆、灯座保持原来的人尺度高度，人物没有随巨殿一起拉高。仍只制作单座巨殿，不加入下一阶段角色控制。

主要实现路径：

- `src/runtime/palace.ts`：分组作者变换、构件与世界尺寸测量；既有静态合批仍保留。
- `src/runtime/roof.ts`：三层屋面共用的曲面算法；绕序和法线检测覆盖新增顶层尺寸。
- `public/assets/palace/source-manifest.json`：更新实际尺寸、构件层数、变换和未启用的物理作者代理。
- `public/runtime-config.json`、`quality/acceptance-profile.json`：修订后的固定远景、阶前和人高机位。
- `scripts/quality/p02-browser.mjs`：额外核对真实世界柱身／人物高度，保持图片重现、完整屋顶范围与射线深度检查。

在云端执行 `npm run gate -- --through P02`，继续实跑 P00—P02。报告按新的唯一 run-id 存放；本轮审核入口新增为 `quality/reports/P02-MONUMENTAL-REVIEW.md`，与旧的 `P02-REVIEW.md` 分开。当前新截图仍等待人工评审；目标 Windows 性能证据仍缺，P02 保持 BLOCKED，不进入 P03。

素材依然由仓库内程序生成，无新增外部图片、模型、字体或运行网络依赖。不合并、不部署。旧文档中的 70 米和双重檐描述是第一版样本记录，当前尺度以本文件和更新后的来源清单为准。
