# P02 巨殿视觉样本

本轮在云端制作单座巨殿的原创参数化视觉样本。开发分支 `feat/tiangong-p02-20261021` 包含完整源资料、P00/P01 和本轮实现。原始 `docs/天宫HTML/` 16 个文件保持字节不变。当前样本等待人工视觉评审与真实 Windows 设备代价记录，不能标记 P02 已验收，不能进入 P03。

## 云端复现

```bash
bash scripts/setup-p01-cloud.sh
npm run dev
npm run gate -- --through P02
```

Vite 只监听云端 `127.0.0.1`。浏览器通过平台端口预览访问；用户电脑不需要开发工具。生产复现为 `npm run build` 后 `npm run preview`。B 最终交付仍采用回环静态服务，本轮构建不是最终 A/B 离线包。不合并、不部署。

门禁实跑 P00—P02。退出码 2 表示必要视觉／目标机证据仍为 BLOCKED；退出码 1 表示技术检查失败。必需真实目标设备的证据不能由云端 SwiftShader 代替。

## 视觉与尺度

参考 `IMG_20261019_161331.jpg` 的巨柱、深檐、格窗和人物比例，参考 `IMG_20261019_161156.jpg` 的长阶与云海。所有十张参考图继续保留；本轮没有把参考图贴到背景或作为游戏纹理，也没有推断其生产使用许可。

工程样本以米计：台面高 12，柱体高约 36，主屋面脊高 70，尺度人物高 1.75；屋脊装饰略高于屋面脊。近景机位眼高为台面上 1.7 米。屋顶是实际曲面网格，重复瓦垄、梁柱等静态构件按材质合批；云海为固定种子的连续噪声曲面。石、木纹理、环境立方体和天空渐变均由本仓库代码生成，无外部运行资源。

采用 PBR 材质、方向主光、1024 阴影贴图、环境光照、固定曝光和时间。三个固定机位坐标是本轮工程构图，尚待用户认可。远景要求完整屋顶轮廓可见；阶前展示长阶与柱列；人高仰视特意进入檐下，以局部构图检查高度和纵深。

尺度人物只是静态参照。碰撞代理不可见且未启用；屋顶包围盒只标记未来物理作者意图，不能充当已完成的屋顶可落碰撞。未加入行走、飞行或角色控制。

## 核查与人工评审

- P02-01：实际加载本地资产、核对运行尺度与来源清单、核对三个审核机位、检查远景屋顶包围范围在视口内。
- P02-02：同机位重复及重建场景的 PNG 逐字节一致；保存三处候选图供人工判断。没有自动更新正确画面基线。
- P02-03：三个机位对实际三角网格进行射线拾取，记录命中的构件、距离和世界坐标，并比较实际像素变化。
- P02-04：记录真实逐帧 draw calls、三角形、材质／纹理数量、生产文件大小、RAF 间隔和 CPU 提交耗时。云端软件渲染和测试截图开销包含在读数中，不能解释为目标 GPU 帧时间或 Windows 帧率。

人工需要判断：小人物与巨殿的比例是否足够宏大、屋顶和柱列轮廓是否值得继续、主光和云海方向是否可接受。复杂雕刻、最终云海和参考图级美术仍未完成。首次生成的截图只是待审核候选。目标 Windows 的硬件、GPU/驱动、分辨率、画质和帧时间分布尚缺；开发继续留在云端，设备实测是后续验收证据，不要求在用户电脑开发。

## 执行预算与历史证据

首轮云端软件渲染的三机位与重建检查耗时数分钟，因此在正式累计运行前把阶段进程上限明确设为 600 秒、P02 浏览器子进程上限设为 480 秒。该超时不构成性能目标，不放宽画面或目标机断言。开发用截图目录带 `visual-development` 标记，不冒充候选指纹绑定的正式门禁。
