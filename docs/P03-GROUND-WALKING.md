## 云端运行

```bash
bash scripts/setup-p03-cloud.sh
npm run dev
npm run gate -- --through P03
```

开发服务仅监听云端 `127.0.0.1`，通过云端平台预览端口访问。点击画布取得焦点，WASD／方向键行走，拖动旋转观察方向，滚轮缩放；松键、离开画布焦点、窗口失焦及后台切换会清除输入。按钮切换跟随观察位置，不切换玩家状态。没有要求在用户电脑安装或运行开发工具。

默认出生在巨殿前台面。可走进柱廊、通过台面前缘的连接平台和长阶抵达底部平台。人物为 1.75 米比例占位模型，当前没有行走动画、跳跃或飞行操作；相机避障、完整双视角和坠落恢复属于后续阶段。

## 代码与状态写入

| 路径 | 用途 |
| --- | --- |
| `src/game/input.ts` | 真实键盘输入、相机水平基向量映射、斜向归一化、焦点与释放 |
| `src/game/session.ts` | 锁定 Rapier 0.21.0 的 WASM 初始化、运动学胶囊与 LocalSession 提交 |
| `src/game/terrain.ts` | 独立碰撞构件、地形矩阵和冻结参数 |
| `src/game/view.ts` | 可替换的 1.75 米人物占位、连接平台与夹具显示 |
| `src/runtime/application.ts` | 固定步调度、相机／人物读快照、异步初始化与销毁 |
| `quality/fixtures/P01/`、`quality/fixtures/P02/` | 当前生产核心上的旧阶段固定场景输入 |
| `quality/fixtures/P03/runtime-config.json` | 可重复的平地、墙角、坡阶与边缘场景 |
| `tools/tiangong/tests/ground.test.mjs` | 14 项真实 WASM 物理／时钟／状态检查 |
| `scripts/quality/p03-browser.mjs` | 真实按键、松键和焦点、默认巨殿、生命周期与显示对齐 |
| `scripts/quality/stages/P03.mjs` | 本阶段真实入口及证据绑定 |

输入只产生 PlayerIntent；Rapier 控制器求解位移；LocalSession.commitSimulationResult 是人物状态唯一提交方；显示人物和相机读取冻结快照。状态位置表示胶囊中心。胶囊高 1.75 米、半径 0.3 米，轴固定 +Y；胶囊绕 Y 旋转不改变物理形状，人物朝向单独读取状态 yaw，避免把无意义的胶囊旋转引入扫掠精度。

地面垂直速度置零，离地后显式累积重力；台阶贴地矫正不会作为向上弹射速度。碰撞后水平速度从实际位移取得。支撑面来自真实射线／控制器接触，不靠画面判断。每次提交校验 tick、有限值及身体位置，快照深冻结。销毁时释放输入监听、Rapier 控制器、世界和 Babylon 场景；异步初始化被中止后也会释放新建资源。

## 参数与地形

固定 60 Hz、行走 3 米／秒、胶囊皮肤间隔 0.02 米、可跨台阶 0.35 米、贴地 0.45 米、最大上坡 40°、滑坡起点 45°、重力 9.81 米／秒²；全部是工程起始值。低帧率时仍受 P01 的最多五步补算限制，不将软件渲染墙钟速度作为目标机性能。

夹具覆盖平地、正交墙角、三阶 0.25 米台阶、禁止的 0.7 米台阶、约 17° 坡、约 53° 坡、3 米高平台边缘。真实宫殿路径另覆盖 60 级 0.3 米长阶、上下平台和顶部连接。长阶上行检查预算 60 逻辑秒，检查真正到达台面、无异常弹高和穿透；它与平地 3 米／秒速度断言分别验证。

大型凸盒与小胶囊的切向扫掠出现过约 5 厘米／秒的间歇损失，之后改为封闭三角盒并修正内部边缘；没有放宽平地速度容差。物理仍为低复杂度独立碰撞网格，不直接把复杂宫殿渲染网格交给求解器。台阶上行存在受约束的矫正过程，不把理想平地路程当作台阶到达时间。
