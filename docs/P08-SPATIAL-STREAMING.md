# P08 三维分区与碰撞交接

用户指令“执行p08开发”，从 P07 交付 `f2d82ac` 接续，分支 `feat/tiangong-p08-streaming-20261029`。

## 当前可运行的工程预览

```bash
bash scripts/setup-p08-cloud.sh
npm run dev
npm run gate -- --through P08
```

分区为 3×4×5 共 60 个不重叠 AABB：x 分界 -35/35，y 分界 24/112/200，z 分界 -48/48/160/256，外包范围 ±1024 米。包含江南地面、穿云上升、巨殿外部、中央室内和屋顶。它们是可调整工程初值，不扩建地图。`node tools/author-p08-zones.mjs` 生成带哈希、来源与依赖的分区资源；每个碰撞体保持原 253 个作者形状，不简化。跨界形状由物理引用计数共享。

原巨殿、水乡、云海、灯光和人物视觉资源整体先常驻。这是本轮明确的视觉基线，尚未声称实现细粒度渲染网格／材质卸载或 LOD；P08 动态取得、激活和回收的实际资源为分区碰撞字节、解析结果和 Rapier 碰撞体。静态视觉初始化接入一次，分区没有额外 GPU 上传。原作者文件、P02 固定三机位与原始 16 个资料仍保护。

调度器使用当前位置、速度和观察方向两秒预测，14 米预取、28 米保留迟滞，最多两个读取，每帧最多一次激活；附近胶囊碰撞优先。状态分别为 loading/prepared/ready/error，只有数据哈希通过且实际碰撞接入物理世界后才 ready。旧任务取消后结果不能接入新代，当前支撑所依赖的已激活分区保留。角色每个固定步先做覆盖整个胶囊的扫掠 AABB 准入，跨水平、竖直和室内边界同样生效。越出世界外包范围也暂停。

当前提案：前方未就绪时，在已准备区域内暂停人物本步移动，保留物理位置、落脚支撑和模式；显示等待或失败提示。失败不自动无限重试，按“重试区域加载”后再请求。加载好后可继续原输入，允许向已就绪方向退回。该提案记录 `quality/streaming-rules/P08-20261029.json`；默认等待策略是“保留支撑、禁止进入未就绪区域”要求的可逆工程实现，开发验证可据此通过；用户偏好保持未确认，不以开发成功冒充用户选择。

长距离往返暴露 Rapier 大水平三角地面的接缝下陷：仅当上一帧已接地、同一个实际射线支撑面法线竖直、控制器本步异常向下超过 5mm 时，按真实支撑高度约束胶囊的本步位移。仍由 LocalSession 提交物理运动，台阶／坡度／屋面规则和 0.01 米穿透容差未放宽。所有旧物理测试重新运行。
