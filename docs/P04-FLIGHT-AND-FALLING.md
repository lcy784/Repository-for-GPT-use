## 运行与操控

```bash
bash scripts/setup-p04-cloud.sh
npm run dev
npm run gate -- --through P04
```

点击三维场景取得键盘焦点，WASD／方向键相对镜头水平移动；F 切换飞行，空格上升、Ctrl 下降，松键悬停。F 按住或键盘重复事件不会反复切换。停止飞行会清除飞行竖直速度并开始重力下落；坠落途中可再次按 F 起飞。向下飞行遇到可行走的支撑面会落地，之后恢复地面控制。空格在地面不触发跳跃。

窗口或画布失焦清除移动按键和待处理的飞行切换；飞行悬停，坠落继续受重力影响。页面隐藏时暂停渲染和模拟，返回后重置时钟，不补算后台经过的时间。拖动旋转观察方向，滚轮调整观察距离。当前仍是跟随观察相机和 1.75 米占位人物。

默认页面在已审巨殿台面出生。P04 增加了实际屋面和顶棚碰撞，可飞到高处或降落在坡度允许的屋面；完整屋顶可达区域和地面至天宫路线仍由 P06 确认，不以 P04 的物理能力代替完整体验验收。

## 工程参数与边界

- 默认飞行速度 10 米／秒，在 `public/runtime-config.json` 的 `flightSpeedMetersPerSecond` 调整；当前验证上限为 60 米／秒。它是可调的初始工程参数，不固定最终地图、路线耗时或平衡。
- 三维方向统一归一化，避免水平加升降的斜向速度变大；飞行不使用地面吸附或自动跨阶。
- 60 Hz 逻辑步内使用 Rapier 胶囊扫掠，较长位移再细分为每段不超过 0.2 米。不是把人物位置直接加到障碍物另一侧。
- 地面已获支撑时由控制器维持接地，重力从失支撑后生效；消除向地板反复施加向下位移引起的偶发切向卡顿，行走速度和 0.01 米容差没有放宽。
- 安全位置需连续接地至少 30 逻辑步，并以四周射线验证足够的可站立面积。低于测试边界 y=-80 米时，明确回到最近记录的稳定位置，清除速度，下一步重新确认支撑。该恢复有独立事件，不作为穿透或卡住的通用补丁。
- 不设能量、生命值或坠落伤害。y=-80 仅为本轮坠出场景恢复边界，不定义最终世界尺寸。

P04-01 反复起飞／退出／落地至少 10 轮，覆盖悬停、中途重新起飞、下降接地和安全位置恢复。P04-02 在速度上限验证 8 厘米薄墙、屋面上下侧、长帧和实际巨殿屋面。P04-03 使用真实原生 Chromium 标签页检查飞行、坠落时后台冻结和返回，同时重放 30／60／144 Hz。P04-04 检查落地后行走和单一物理／状态／显示位置，并由累计链重跑全部 P03 地形与真实输入。

最终状态以 `quality/reports/P04-REVIEW.md` 索引的完整累计报告为准。开发调试检查不授予阶段 PASS。每次正式运行均从 P00 累计至 P04，生产构建、原始状态、截图和日志均绑定本次候选。
