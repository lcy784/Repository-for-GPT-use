# P05 古装临时人物、动作与双视角

分支 `feat/tiangong-p05-avatar-camera-20261023`。用户要求开发 P05，并对人物与镜头建议回复：

> 采用这组规则，人物细节和镜头参数先用可调整的初版

最低规则已登记在 `quality/avatar-camera-rules/P05-20261023.json`。人物为 1.75 米白衣青玉、中性简化古装；包含站立、行走、飞行和坠落动作。此选择确定临时样本方向，不代表最终美术精度验收。

## 运行与操作

```bash
bash scripts/setup-p05-cloud.sh
npm run dev
npm run gate -- --through P05
```

点击场景后，WASD／方向键相对观察方向移动；F 起停飞行，空格／Ctrl 升降，松键悬停。V 或界面按钮切换第一／第三人称，拖动转向。无需鼠标锁定授权。第一人称隐藏自身模型，第三人称可见人物；贴近障碍导致镜头距离不足 0.7 米时也暂时隐藏自身，避免衣服遮满画面。

第三人称滚轮调整期望距离 2—12 米，初始 6 米（可在 `public/runtime-config.json` 修改 `thirdPersonDistance`）。遇墙或屋檐立即收近，障碍移开后逐渐恢复到期望距离。切换保留观察方向和人物位置。画布／窗口失焦清除拖动、按键和待处理操作；页面隐藏时暂停模拟，返回后可继续操控。

## 人物与动作

- `public/characters/p05/traveler.glb` 为本项目原创的自包含 GLB，来源与再生成方法见同目录 README、`tools/author-p05-avatar.py`。无第三方人物、贴图或动作下载。
- 使用关节节点层级及基础 TRS 姿态动画，未声称使用蒙皮或写实人体；四组 GLB AnimationGroup 以权重混合，约 0.12 秒过渡。
- 按物理状态选择 idle／walk／fly／fall，动作进度由已完成的固定逻辑步采样。显示根节点每帧只读取 LocalSession 位置；动作轨道不包含根节点位移。
- 作者坐标脚底 y=0、正面 -Z；模型容器相对胶囊中心下移 0.875 米。渲染边界转换模拟 yaw 的符号，保持朝向与实际移动一致。
- 第一人称相机位于脚底上方约 1.6 米；身高、胶囊和地板边距继续按原比例检查。临时人物的关节、衣袖和下摆可见变化，不以动作名称字符串代替实际姿态。

## 相机与状态边界

`PlayerCamera` 只读人物快照和物理查询。第三人称从人物眼位到期望镜头做半径 0.16 米的球形扫掠，排除自身胶囊，保留近裁面和额外间距；墙角、门洞和屋檐统一用真实 Rapier 碰撞面处理。相机没有移动人物或提交人物状态的入口。

P05 默认仍是原巨殿；独立遮挡夹具含墙边、门洞、门额和屋檐。该夹具不扩展完整产品地图。P04 默认配置另存为 `quality/fixtures/P04/palace-runtime-config.json`，与 P01—P03 夹具一样继续在当前生产核心上运行。
