## 安装和扫描

在云端仓库根目录运行：

```bash
bash scripts/setup-cloud.sh
python3 scripts/scan-secrets.py
```

安装脚本将锁定版本的 Python 工具安装到仓库的 `.cloud-tools/`，该目录已被 Git 忽略。工具包安装需要网络访问 Python 包索引及下载域名。也可通过 `CLOUD_TOOLS_DIR` 指向仓库外的云端虚拟环境。

扫描脚本遍历仓库文件（包括未跟踪文件），跳过 Git 元数据、工具环境和常见依赖目录；底层工具还会过滤部分扩展名、锁文件及其他内容，因此不等于逐字节检查所有文件。发现疑似凭据时退出码为 1，仅输出文件路径、行号和检测类型，不输出命中值。工具缺失、路径不存在、路径位于仓库外或执行失败时退出码为 2。扫描路径也可显式指定：

```bash
python3 scripts/scan-secrets.py docs
```

扫描使用 `--no-verify`，不把疑似凭据发送给外部服务验证。自动扫描主要针对凭据，不覆盖所有个人信息、商业秘密和二进制附件。收到原资料后必须另外进行人工内容审查。避免将包含个人信息的文件名和路径放进可公开的报告。
