## 2. 产品定位与用户目标

### 2.1 产品定位

面向 Windows 电脑的三维探索与观景作品。世界包含参考现有江南 HTML 元素并扩大的地面，以及参考用户图片的多宫殿天宫建筑群。

玩家操控古装人物，在世界中行走、自身飞行，并切换第一与第三人称。玩家能够从地面飞上天宫，进入宫殿，在屋顶降落，并具有重力、坠落及水中活动体验。

先提供简易离线 HTML 版，再提供包含模型和素材文件夹的完整离线项目版。后续开发支持 3—5 人共同观景的联机版本。

### 2.2 已确认用户目标

| 编号 | 用户目标 |
| --- | --- |
| G-01 | 体验宏大的中式建筑，画面尽量接近全部参考图片 |
| G-02 | 亲自控制人物探索，包括地面行走、飞行与不同视角观察 |
| G-03 | 从江南水乡飞往云海中的天宫 |
| G-04 | 以观景为主要活动，并进行已提出的轻量互动 |
| G-05 | 在 Windows 电脑上断网使用离线版本 |
| G-06 | 后期与 3—5 人一起行走、飞行和看风景 |

### 2.3 已确认取舍顺序

**建筑宏大 > 画面逼真 > 运行流畅 > 可探索范围。**

该顺序不取消任何已确认需求，也不自动降低用户提出的 60 FPS 目标。如发生冲突，具体取舍仍需确认。

## 4. 核心需求

核心需求直接支撑“宏大建筑中的可控人物观景”及本机离线使用。每项均说明用户要解决的问题，并将未明确部分留给问题清单。

### C-01：宏大天宫建筑群

- **解决的问题：** 用户希望亲身感受参考图中的巨大中式建筑和尺度震撼。
- **已确认需求：**
  - 天宫采用多宫殿建筑群。
  - 突出建筑宏大。
  - 尽量实现全部参考图片所呈现的场景。
- **来源：** 原始需求；补充回答 2、3、6。
- **结果核对：** 对照参考图及实际人物视角审核建筑规模感和建筑群表现。
- **尚未解决：** 建筑数量、完整地图布局、具体地标清单、尺度数值及允许简化的细节，见 U-04。

### C-02：接近参考图的真实画面

- **解决的问题：** 用户希望作品在视觉上尽量接近图片，尤其是巨殿尺度与光照。
- **已确认需求：**
  - 三维世界的样子要真实，尽量和图片一样。
  - 尽量覆盖全部图片，不自行只选其中一张作为目标。
  - 最终核心体验中的巨殿尺度和光照接近指定参考图。
- **来源：** 原始需求；补充回答 2、3、12。
- **结果核对：** 用参考图对照实际画面，评估尺度与光照是否符合用户期待。
- **尚未解决：** 相似程度、审核机位、细节精度及简化范围，见 U-04。本文不把审美解释或具体画面技术写成用户要求。

### C-03：扩大的江南地面

- **解决的问题：** 用户需要能探索的地面场景，作为水乡观景与前往天宫的空间。
- **已确认需求：**
  - 地面元素参考现有 jiangnan-offline.html。
  - 参考元素并扩大地面范围。
  - 地面探索尺度以步行约 6—8 分钟为目标；飞行更快。
- **来源：** 原始需求；补充回答 5、6。
- **结果核对：** 地面表现体现江南参考元素；按后续确认的路线和速度核对 6—8 分钟目标。
- **尚未解决：** 地图边界、测量路线、步行速度、飞行速度，以及保留哪些具体元素，见 U-05。
- **范围边界：** 未要求完整复制原有地图，也未决定必须沿用其源码。

### C-04：可操控的古装主人物与行走

- **解决的问题：** 用户需要以人物身份参与探索，主动决定去哪里、看什么。
- **已确认需求：**
  - 有一个可自由操控行走的主人物。
  - 主人物为古装人物。
  - 接受临时人物，不要求太真实，有基本动作幅度即可。
- **来源：** 原始需求；补充回答 8、12。
- **结果核对：** 用户能控制古装人物行走，人物有可见的基本动作表现。
- **尚未解决：** 输入操作、人物外观、具体动作清单及移动速度，见 U-06、U-10。

### C-05：人物自身飞行与地面至天宫的抵达

- **解决的问题：** 用户需要探索不同高度，并亲自从水乡到达云海中的天宫。
- **已确认需求：**
  - 人物自身能够飞行。
  - 能从地面飞上天宫。
  - 飞行比步行更快。
- **来源：** 原始需求；补充回答 5、6、7、12。
- **结果核对：** 用户能操控人物从地面飞到天宫。
- **尚未解决：** 飞行速度、转向与升降规则、起停规则、天宫高度、飞行耗时及加载过渡体验，见 U-06、U-07。
- **范围边界：** 未确认御剑、坐骑、飞行能量或无加载过渡等要求。

### C-06：第一与第三人称切换

- **解决的问题：** 用户需要用不同视角观察世界，并看到人物与巨型建筑的尺度关系。
- **已确认需求：**
  - 可使用第一人称。
  - 可使用第三人称。
  - 两种视角能够切换。
- **来源：** 原始需求；补充回答 12。
- **结果核对：** 在探索过程中可以切换两种视角。
- **尚未解决：** 镜头距离、旋转方式、遮挡表现、第一人称是否显示身体，见 U-10。

### C-07：宫殿内部可进入

- **解决的问题：** 用户需要进入建筑内部观景，而不只停留在建筑外部。
- **已确认需求：** 宫殿内部可以进入。
- **来源：** 补充回答 7。
- **结果核对：** 用户能够进入交付范围内确认开放的宫殿内部。
- **尚未解决：** 开放哪些宫殿、是否全部开放、内部空间与装饰深度，见 U-08。
- **范围边界：** 未确认所有建筑和所有房间必须开放。

### C-08：屋顶降落

- **解决的问题：** 用户需要在高处落脚，从屋顶观察建筑群和周围景观。
- **已确认需求：** 屋顶允许人物降落。
- **来源：** 补充回答 7。
- **结果核对：** 人物可以在交付范围内确认可降落的屋顶落脚。
- **尚未解决：** 可降落建筑及区域、屋面活动边界，见 U-08。

### C-09：重力与坠落

- **解决的问题：** 用户希望人物移动具有重力和坠落体验。
- **已确认需求：** 人物具有重力与坠落。
- **来源：** 补充回答 7。
- **结果核对：** 按后续确认的运动规则核对重力和坠落表现。
- **尚未解决：** 飞行与重力的关系、坠落后处理、途中能否重新飞行，见 U-06。
- **范围边界：** 未确认坠落伤害、死亡、生命值或惩罚系统。

### C-10：水中活动

- **解决的问题：** 用户需要在包含水域的世界中进行水中活动。
- **已确认需求：** 人物可以在水中活动。
- **来源：** 补充回答 7。
- **结果核对：** 按后续确认的水中活动定义验证人物能力。
- **尚未解决：** 活动是涉水、游泳、潜水还是组合，以及具体规则，见 U-09。
- **范围边界：** 不能自动把“水中活动”写成必须完整游泳、潜水或带呼吸系统。

### C-11：Windows 本机离线使用

- **解决的问题：** 用户需要在自己的电脑上单机观景，断网时也能使用。
- **已确认需求：**
  - 目标设备为 Windows 电脑，当前只需要电脑。
  - 简易 HTML 版和完整项目版均可断网使用。
- **来源：** 原始需求；补充回答 1、4。
- **结果核对：** 在所需交付文件准备完整后，断开网络仍能启动并使用对应离线版本。
- **尚未解决：** Windows 版本、运行入口、必要运行环境及启动流程，见 U-03。
- **范围边界：** 未确定浏览器品牌、必须单文件或禁止本地启动程序。

## 8. 用户操作流程（仅表达已确认能力）

以下流程用于串联已确认需求，不规定出生点、操作按键、加载方式或固定游玩顺序。

### 8.1 核心观景流程

1. 在 Windows 电脑上使用离线版本。
2. 操控古装人物在江南地面行走。
3. 操控人物自身飞行，从地面飞上天宫。
4. 切换第一和第三人称，观察宫殿建筑群及其尺度和光照。
5. 进入宫殿内部，或在屋顶降落，继续观景。

### 8.2 其他已提出活动

- 在水中活动。
- 体验重力与坠落。
- 关门、坐下、截图。

昼夜、天气、天象和 NPC 在确定交付阶段后纳入对应版本流程；本流程不预先规定其触发方式。
