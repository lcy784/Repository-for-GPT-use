## 资源与所有权

`public/registry/p07.json` 登记稳定 ID、版本、SHA-256、依赖、作者源文件、碰撞引用及 LOD 列表。当前资源为巨殿／江南程序几何配方、原创人物 GLB、精确导出的 253 个碰撞体、世界元数据，另有诊断页专用 2×2 纹理。坐标统一为米、右手系、Y 向上。世界中的两个区域仅描述边界，不触发卸载。当前无 LOD，空列表如实保留。

`node tools/author-p07-assets.mjs` 显式重新导出资源。生产构建只校验清单及作者源哈希，不自动修复失配；缺 ID、重 ID、缺依赖、循环、无效碰撞引用或内容变化均报错。原 `public/assets/` 和宫殿作者模块不改写。

HTTP 适配器只读取本地根目录中的相对路径；嵌入适配器读取持有的字节表，接口已实测但尚非最终 A 包。内容读取后校验哈希，再允许解码。清单本身由构建候选指纹保护，不宣称可抵御清单与资源同时被替换的攻击。

每个消费者持有可重复安全释放的 lease；同一 key 的并发消费者共享一次读取／解码。最后一个引用释放才销毁资源。取消立即拒绝该消费者，不影响其他引用；不能中断的旧解码完成后销毁其结果，不能覆盖新一代。失败透明报错，只有新的显式请求／重新载入才重试，没有后台无限重试。

字节与解码资源分池；场景范围只拥有自己创建的网格、节点、材质、纹理及光源，异常中途也清理。P06 原巨殿与江南放置过程作为同一个场景资源，避免共享已被位移的可变场景。人物、地面显示与场景都绑定 Application 生命周期，停止／失败同时释放物理与资源，重启新建范围。
